Activity — design explorations

Three takes on the audit trail. Same sample data, same design tokens, same draft-grouped cards. Switch between tabs to compare. The goal is to pick a primary navigation axis: scroll-through-time, jump-by-day, or hybrid.

Stream model. Reverse-chronological feed grouped by draft, with sticky day headers as you scroll. Filter chips and search at the top stay pinned. A small calendar icon opens a date popover for the rare "jump to a specific day" case. This is what GitHub Activity, Linear inbox, and Vercel deployments all do.
Two-pane model. Left rail lists every active day with its event count — you see density at a glance and click to load. Right pane shows the selected day's draft groups. Like email apps, GitHub Actions runs, log viewers. Cost: dies on mobile (left rail collapses to a horizontal scroller, less elegant).
