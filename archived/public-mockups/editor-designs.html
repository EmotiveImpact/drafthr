Editor — design options, grounded in current chrome

Every variant below uses the exact same shell as the editor that's shipped today: the h-12 header with brand + breadcrumb + view toggle + invite/export, the 36px secondary toolbar with Tone + WP, the 240/canvas/380 three-column body. The only things that change are the specific elements called out in the yellow "What changed" box. Yellow chips on each mockup point at the exact element being touched.
