6 — Composition rules

  1. One solid CTA per region. "Run compliance check", "Generate contract", "Export". Never two solid buttons in the same row.
  2. Cards have one shape. 1px --line border, no shadow, --r-lg radius, --s-5 padding.
  3. Status colour only on dots, badges, and table-cell text. No coloured borders, no coloured backgrounds on cards.
  4. Density never mixed. A view is either comfortable (44px row) or compact (36px row).
  5. One header per route. Editor included. Move overflow controls into a "More" menu before adding a second bar.
  6. Avatars come from the primitive. Same palette, same radius, same letter rules. The avatar stack is owned by one component.
  7. Marquee headlines are serif. Source Serif 4. Section headlines (≤24px) are sans. Don't mix faces in the same heading group.
  8. The brand mark is a chip, not an icon. 32×32 with a serif "D" — replaces every Lucide ScrollText.
  9. Letter paper is a card with serif body. Same paper renders in preview, split, and export.
  10. Right-rail tabs replace stacked toolbars. Don't add a second action row in any rail.
