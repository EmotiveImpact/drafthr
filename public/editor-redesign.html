Editor redesign — less chrome, same functions

Two design lenses applied to the current editor. Goal: keep every function but reduce vertical chrome, sharpen visual hierarchy, and let the document and the AI panel breathe. Side-by-side mocks below, then a row-by-row diff at the bottom.

Google FUNCTIONAL HIERARCHY

  • Group by frequency, not category. Tone + Without-Prejudice + Regenerate-all all live in the secondary toolbar today, but the user touches Regenerate-all 10× more often than Without-Prejudice. Re-rank.
  • Status everywhere. The section list shows numbers but not state. Add a status dot per section (ready / streaming / edited / empty) and a progress header ("8 of 13 ready").
  • One primary CTA per region. Already true — Export is the only solid button in the topbar. Don't dilute it.

Apple REDUCE TO REVEAL

  • Hide what's not active. The 4-card "What I can do" panel takes 40% of the right rail before the user has typed anything. Replace with one focused empty state + the input below the fold-line is the discovery.
  • Collapse what's secondary. Without-Prejudice toggle is used once per draft. It belongs behind a Tone-style popover, not pinned to the toolbar.
  • Quiet the chrome. Section list at 200px not 240px. Borders softened to hairlines. Tab strip in the rail loses its bottom border in favour of an underline-on-active style.

Row-by-row diff

What changes, what stays.

01

Two toolbars → one

The h-9 secondary toolbar disappears. Tone, Without-Prejudice, and Regenerate-all consolidate.

How

Regenerate-all stays visible (it's used every drafting session) — moved to the topbar as a small outline button. Tone + Without-Prejudice fold behind a ⚙ Document popover trigger next to it. Same total controls, one fewer horizontal strip.

02

Section list gets a heartbeat

Numbered items today say nothing about state. Now each row carries a coloured status dot.

Status legend

ready edited / streaming empty. Header shows "8 of 13" so the user knows how close they are to done. Width drops 240px → 200px.

03

AI empty state — tight, not tall

The "What I can do" stack of four cards is gone. It pushed the input below the fold-line.

Replacement

Centred brand mark + one heading + one sentence. The four quick-prompt chips inside the composer are the capability discovery — they're labelled by what they do ("Tribunal-ready", "+ clause", "Tighten", "Summarise") so clicking one teaches you what the tool can do.

04

Breadcrumb compresses

Today: "Letters / Formal Grievance / to employer · UK · ⚠ Needs review". Five separate pieces.

Now

"Formal Grievance · UK · Assertive · ⚠". The "Letters" prefix drops (the breadcrumb still navigates back via brand-mark click). Jurisdiction + tone merge into one meta line. The amber needs-review chip becomes a single icon with tooltip — colour does the work the words were doing.

05

Comments tab carries a count

Today: just "Comments". Doesn't tell you anything's there.

Now

Black pill with the unresolved count next to the tab label. Same affordance Gmail / Linear / Notion use to draw the eye.

06

Composer keyboard hint moves into the scope row

"⌘ + Enter to send · The AI may propose section changes — review with Apply before they go live" was a two-line footer.

Now

"⌘ + Enter" right-aligned in the scope chip row. The "Apply before they go live" bit moves into the empty state copy ("Edits stage as proposals — you Apply before they touch the letter") where the user encounters it first, then it's gone.

07

"Today · 11 May" pill — out of header, into model line

Today: separate pill in the rail body. Useful for trust but visually competing.

Now

Folded into the empty-state badge: "qwen3-max · 11 May". Same info, half the chrome. Once a conversation starts the badge fades behind the chat.
