The three states — progressive disclosure

User climbs the ladder based on workload. Default is the lightest state (pill). The user opts up only when they need more space. State is per-draft — a tribunal claim might live in Pinned mode; a holiday request never leaves the Pill.

💡 Each state is one click away from the next. Pill → click → Drawer. Drawer → Pin → Rail. Rail → Unpin → Drawer. Drawer → ↓ → Pill. No forced wizard, no separate routes.

Wins vs current side-Sheet drawer

• Letter never dimmed. Always full-bright behind the dock.
• AI agent stays. Drawer doesn't overlay or replace it (until State 3 pin).
• Lower visual weight at rest. Pill is 32px tall, not a 28px toolbar button users have to discover.
• Familiar. LinkedIn Messaging, Gmail chat, Intercom widget all use it.
• Mobile-graceful. Pill → full-width bottom sheet → known mobile pattern.
• Future-proof. Dock tray can host Messaging, Comments, Notifications without UI churn.

Costs

• New control surface. The "expand fullheight" + "collapse to pill" gestures need teaching (tooltip on first hover).
• Drawer is narrower (420px vs 560px). Heavy-evidence sessions should pin straight to State 3.
• State complexity. 3 visual states vs the current 2 (drawer/pinned). Worth it because each does one thing well.
• Bottom-of-screen real estate now reserved for docks. Future toasts/snackbars need to clear this zone.

Migration path — 3 commits

  1. Replace Sheet with bottom-docked panel. EvidenceDrawer's floating mode swaps from Radix Sheet (right-side overlay) to a fixed-positioned div at bottom-right. Same content, different shell.
  2. Add the pill (rest state). Mounts always at bottom-right when drawer is closed. Replaces the top-bar Evidence button (or keep both — toolbar pill becomes the shortcut, dock pill is the resting form).
  3. Reorder toolbar. People/Invite pill moves before the avatar cluster (or wherever feels right — closer to where users go to invite).
